ขั้นที่ 3 จาก 5 · เชื่อมต่อฐานข้อมูล Cloud

☁ เชื่อมต่อฐานข้อมูล Cloud (Supabase)

ใช้เก็บข้อมูลของแอป

🚀 สร้าง Supabase Project:
1. เปิด supabase.com → กด Start your project
2. Sign in ด้วย GitHub (บัญชีที่สมัครในขั้นที่แล้ว)
3. กด New project → ตั้งชื่อ → ตั้ง Database Password → Region: Southeast Asia (Singapore) → กด Create new project
4. รอ 1–2 นาที ให้ระบบเตรียมพร้อม

🔗 หา Supabase URL:
Dashboard → กดปุ่ม Connect (ด้านบน) → เลื่อนดูหัวข้อ Frameworks
  → คัดลอกเฉพาะส่วน https://xxxxx.supabase.co

🔑 หา Anon Key:
Dashboard → Project Settings (เมนูด้านข้าง) → API Keys (เมนูด้านข้าง)
  → หัวข้อ Legacy API Keys → คัดลอก anon key (ขึ้นต้นด้วย eyJ...)
⚠ URL หรือ Key ดูไม่ถูกต้อง ตรวจสอบอีกครั้ง
ขั้นที่ 4 จาก 5 · สร้างฐานข้อมูล

🗄 ตั้งค่าฐานข้อมูล

รันสคริปต์ใน Supabase เพื่อสร้างตาราง

  1. ไปที่ Supabase Dashboard → SQL Editor
  2. กดไฟล์ด้านล่างทีละไฟล์ → คัดลอกโค้ดทั้งหมด
  3. วางในช่อง SQL Editor → กด Run
  4. ทำซ้ำแบบนี้ทั้ง 3 ไฟล์ ตามลำดับ
📄 1. schema-clean.sql (ตารางหลัก — ฐานสะอาดสำหรับโรงเรียนใหม่) 📄 2. push-schema.sql (การแจ้งเตือน) 📄 3. quiz-schema.sql (แบบทดสอบ)
