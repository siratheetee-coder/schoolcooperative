เปิดแจ้งเตือนเด้งทำไม?

🔔

ถ้าตั้งค่านี้เสร็จ — เวลามีเหตุการณ์ในร้าน ครูจะได้รับ การแจ้งเตือนเด้งขึ้นที่มือถือ/คอม ทันที (แม้ปิดแอปอยู่ก็เด้ง) เช่น:

  • 💰 นักเรียนขายของได้
  • 📤 นักเรียนส่งคำขออนุมัติ
  • 📦 สินค้าในสต็อกใกล้หมด
  • 📅 ถึงเวรของตัวเอง
✅ ใช้แค่นี้ก็พอ:
• บัญชี Supabase ที่ตั้งค่าไว้แล้ว (ตอนติดตั้งระบบ)
• คอม/มือถือ + เบราว์เซอร์ Chrome หรือ Safari

❌ ไม่ต้อง: ลงโปรแกรมเพิ่ม / เขียนโค้ดเอง / รู้เรื่อง coding
⚠ ถ้ายังไม่ได้ตั้งค่าฐานข้อมูล (Supabase) — กลับไปทำหน้าตั้งค่าหลักให้เสร็จก่อน
⏭ ไว้ตั้งทีหลัง

สร้าง "กุญแจ" ของระบบ

การส่งแจ้งเตือนต้องมี "กุญแจ" 2 ชิ้น เพื่อยืนยันว่าเป็นเรา ไม่ใช่คนอื่นแอบส่ง — กดปุ่มด้านล่าง ระบบจะสร้างให้ทันที ไม่ต้องใช้โปรแกรมอะไรเพิ่ม

✅ สร้างเสร็จแล้ว! เก็บไว้เอาไปใช้ในขั้นถัดไป

🔒 กุญแจส่วนตัว: —
⚠ สำคัญมาก:
• กุญแจส่วนตัว ห้ามแชร์ให้ใครเด็ดขาด (เหมือนรหัสผ่าน)
• อย่าปิดหน้านี้ จนกว่าจะตั้งค่าครบ 5 ขั้น
• ถ้าปิด/refresh กุญแจจะหาย ต้องสร้างใหม่ → กดบันทึกไฟล์สำรองไว้ก่อน
ขั้นตอนที่ 3 จาก 5

ติดตั้ง "โปรแกรมส่งแจ้งเตือน"

เอา โค้ดเล็กๆ ชิ้นเดียว ไปวางบนเว็บ Supabase เพื่อให้มันส่งแจ้งเตือนแทนเรา — แค่ copy/paste ไม่ต้องเขียนเอง

📋 ทำตามนี้ทีละข้อ (ใช้เวลาประมาณ 5-8 นาที)
1 เปิดเว็บ Supabase (จะเปิดในแท็บใหม่): 🌐 คลิกเปิด Supabase
2 คลิกเลือกโปรเจคต์ของโรงเรียนเรา (ที่ตั้งไว้ตอนติดตั้งระบบ)
3 ที่ เมนูซ้ายมือ → หาคำว่า Edge Functions (รูปไฟ้สายฟ้า ⚡) → คลิก
4 คลิกปุ่มเขียว Deploy a new function
→ ช่อง "Name" พิมพ์ว่า: send-push (ตัวเล็กทั้งหมด มีขีดกลาง)
→ ช่อง "Verify JWT" ติ๊กออก ❌ (ไม่เลือก)
5 ลบโค้ดที่มีอยู่ทิ้ง (กด Ctrl+A แล้ว Delete) → กดปุ่มด้านล่างเพื่อ copy โค้ด → กลับไป Supabase paste (Ctrl+V) → กดปุ่ม Deploy function
🔍 อยากดูโค้ดก่อน? คลิกที่นี่
⏳ รอจนกว่าจะขึ้นข้อความ "Deployed successfully" ก่อนกดปุ่มถัดไป
(ปกติใช้เวลาประมาณ 30 วินาที — 1 นาที)
ขั้นตอนที่ 4 จาก 5

ใส่ "กุญแจ" ให้โปรแกรม

เอา กุญแจ 2 ชิ้น ที่สร้างจากขั้นที่ 2 → ไปบอกโปรแกรมว่าใช้กุญแจไหน (ตอนนี้โปรแกรมยังไม่รู้)

🔑 ต้องเพิ่ม 3 บรรทัด ใน Supabase
1 ที่หน้า Supabase ที่เพิ่ง deploy → คลิกที่ชื่อ send-push → ดูที่แท็บด้านบน หา Secrets → คลิก
2 คลิกปุ่ม + Add new secret ทีละบรรทัด ตามรายการด้านล่าง
(Name = ชื่อข้างซ้าย, Value = กดปุ่ม 📋 แล้วไปวาง)
บรรทัดที่ 1
VAPID_PUBLIC_KEY —
บรรทัดที่ 2
VAPID_PRIVATE_KEY —
บรรทัดที่ 3
VAPID_SUBJECT mailto:admin@school.ac.th
💡 บรรทัดที่ 3 (VAPID_SUBJECT): ใส่ อีเมลของครูผู้ดูแล โดยขึ้นต้นด้วย mailto:
ตัวอย่าง: mailto:somchai@gmail.com
⏳ ใส่ครบ 3 บรรทัดแล้ว → รอประมาณ 30 วินาที ก่อนกดถัดไป
(Supabase ต้องอัปเดตให้โปรแกรมรู้จักกุญแจใหม่ก่อน)
ขั้นตอนที่ 5 จาก 5 (สุดท้าย)

ลองส่งแจ้งเตือนดูจริงๆ

เช็คว่าทุกอย่างที่ทำมาใช้งานได้จริง — กดปุ่มแล้วระบบจะส่งแจ้งเตือนทดสอบมาที่เครื่องนี้

1 กดปุ่ม "ทดสอบ" ด้านล่าง
2 เบราว์เซอร์จะเด้งกล่องถาม "ต้องการรับแจ้งเตือนจากเว็บนี้ไหม?" → กด "อนุญาต / Allow"
3 รอ 5-10 วินาที → ต้องเห็น "🎉 ทดสอบสำเร็จ!" เด้งขึ้นมาที่หน้าจอ
ถ้าไม่เห็นแจ้งเตือนเด้งขึ้นมา ตรวจสอบว่า:
• เครื่องไม่ได้อยู่ในโหมด "ห้ามรบกวน" (Do Not Disturb)
• ไม่ได้ปิดเสียง notification ของเบราว์เซอร์
• บน iPhone ต้องติดตั้งแอปก่อน (Add to Home Screen)
