Deploy Edge Function

Edge Function = โค้ดส่ง Push ที่อยู่บน Supabase — copy โค้ดไปวางใน Dashboard

1 เปิด Supabase Dashboard: 🌐 เปิด Supabase Dashboard
2 เลือก project ของคุณ → ไปที่เมนู Edge Functions ทางซ้าย
3 กดปุ่ม Deploy a new function → ตั้งชื่อว่า send-push → ติ๊ก ✓ Verify JWT with legacy secret ออก (uncheck)
4 ลบโค้ด default ออก → คัดลอกโค้ดด้านล่างวางทั้งหมด → กดปุ่ม Deploy function
👀 ดูโค้ด (กดเพื่อขยาย)
ขั้นตอนที่ 4 จาก 5

ตั้งค่า Environment Variables

ใส่ VAPID Keys ที่สร้างไว้ใน Supabase เพื่อให้ Edge Function ใช้ส่ง Push

1 ใน Supabase Dashboard → Edge Functions → send-push → tab Secrets
2 กด + Add new secret ทีละตัว ใส่ 3 ตัวด้านล่าง:
VAPID_PUBLIC_KEY: —
VAPID_PRIVATE_KEY: —
VAPID_SUBJECT: mailto:admin@school.ac.th
💡 VAPID_SUBJECT เป็นอีเมลผู้ดูแล — ใส่อีเมลจริงของครู (เปลี่ยน admin@school.ac.th เป็นของจริง)
⏳ หลังเพิ่ม Secrets เสร็จ — รอประมาณ 30 วินาทีให้ Function รีเฟรช ก่อนทดสอบ
