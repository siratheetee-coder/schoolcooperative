☁ เชื่อมต่อ Cloud (Supabase)

เก็บข้อมูลปลอดภัย · ใช้ฟรีไม่จำกัด

ยังไม่มี Supabase?
1. เปิด supabase.com → Sign in with GitHub
2. New Project (Region: Singapore, Plan: Free)
3. หลังสร้างเสร็จ → Settings → API → คัดลอก URL + anon key
⚠ URL หรือ Key ไม่ถูกต้อง

🗄 ตั้งค่าฐานข้อมูล

รันสคริปต์ใน Supabase เพื่อสร้างตาราง

  1. ไปที่ Supabase → SQL Editor → New query
  2. เปิดไฟล์ schema.sql ใน GitHub repo
  3. คัดลอกทั้งหมด → วางใน SQL Editor → กด Run
  4. ทำซ้ำกับไฟล์ push-schema.sql
📄 เปิด schema.sql 📄 เปิด push-schema.sql
